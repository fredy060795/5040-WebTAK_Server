## Downloads

| Device | File |
|---|---|
| **Windows** (most PCs) | `WebTAK-Server-Windows-amd64.zip` – unzip, double-click `webtak-server.exe` (try) or `Install.bat` (install) |
| Windows on ARM | `WebTAK-Server-Windows-arm64.zip` |
| **Raspberry Pi / Linux** | run `curl -fsSL https://raw.githubusercontent.com/fredy060795/5040-WebTAK_Server/main/install/install.sh \| sudo sh` |
| Linux by hand | `webtak-server-linux-amd64`, `-arm64` (Pi 3/4/5 64-bit), `-armv6` (all 32-bit Pis) |
| macOS | `webtak-server-macos-arm64` (Apple Silicon), `-intel` |

Then open the web interface, set the admin password, create users and scan the QR code with ATAK / iTAK.
See the [README](https://github.com/fredy060795/5040-WebTAK_Server#readme) for details.
